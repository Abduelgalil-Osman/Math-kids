# 🎈 Number Adventure — Fun Math for Kids

Interactive, colorful, mobile-friendly math website for kids (international schools in Saudi Arabia).

## Sections
1. 🔢 Counting & visual representation
2. 🏠 Place value (ones, tens, hundreds, thousands)
3. ➕➖✖️➗ Basic operations with instant feedback, sounds & stars
4. ✖️ Times tables 1–12
5. 🌍 Real-life critical-thinking problems (Saudi context, SAR currency)
6. 🧮 Simple linear equations (3 levels)

Just open `index.html` — no build step needed. Works offline (except Google Fonts).

## Publish with GitHub Pages
Settings → Pages → Deploy from branch → `main` / `/ (root)` → Save.
